# 교무톡 0.1.9

- AI 연결: 설정 → ‘AI 연결’에서 내 ChatGPT 계정으로 로그인하거나(무료 계정도 됩니다) OpenRouter·Google AI Studio 열쇠를 넣습니다. 열쇠와 로그인 정보는 그 PC에만 암호화해 저장하고 학교 서버로 보내지 않습니다.
- AI로 다듬기: 메시지를 쓸 때 맞춤법 다듬기·짧게·정중한 안내 말투를 고르면 원래 글과 나란히 보여 주고, ‘바꾸기’를 눌러야 바뀝니다. AI가 연결되지 않았으면 연결 창이 바로 열립니다.
- 보내기 전 확인: 차별 표현·어려운 행정 말·AI 말투·2026-11-20 같은 날짜 표기를 PC 안에서 확인하고 바꿀 말을 알려 줍니다.
- 수강신청 분반 편성: 한 분반 최대 인원·같은 반 묶기를 정하면 과목마다 분반을 나누고 명단을 엑셀로 저장합니다. ‘AI로 설명 듣기’는 과목별 인원과 분반 수만 AI에 보냅니다.
- 학사일정 달력의 일정마다 등록한 사람이 보입니다. 왼쪽 메뉴 이름을 ‘일정 · 특별실’로 바꿨습니다.
- 화면 색상을 바꾸면 교무톡 마크와 작업표시줄 아이콘도 같은 색으로 바뀌고, 업데이트 뒤 바탕화면 아이콘이 새 마크로 바로 바뀝니다.
- 관리자 ‘기능 설정’에 ‘AI 글 다듬기’를 넣었습니다. 외부 AI 사용을 막아야 하는 학교는 끄세요.

학교 서버와 교직원 PC를 어느 쪽부터 업데이트해도 됩니다. 관리자 ‘기능 설정’의 ‘AI 글 다듬기’ 스위치는 서버가 0.1.9여야 보입니다(그 전에는 켜져 있는 것으로 봅니다).

수강신청에 쓰는 구글 코드는 0.1.8과 같아 다시 붙여넣지 않아도 됩니다.
