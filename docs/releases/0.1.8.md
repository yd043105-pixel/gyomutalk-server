# 교무톡 0.1.8

- 수강신청을 넣었습니다. 교육과정 담당 선생님이 학생마다 개인 링크를 보내 선택과목을 받고, 학생 화면은 학교가 만든 구글 계정에서 열립니다. 처음 한 번 ‘구글 연결’에서 코드를 붙여넣어 배포합니다(그림 안내 포함).
- 학생 이름은 구글에 보내지 않습니다. 구글에는 무작위 번호와 고른 과목만 남습니다.
- 과목별 인원, 학기별 ‘함께 듣는 학생 수’, 반별 미제출 명단을 보고, 폐강을 반영하며, 학급별 수강신청 확인서를 인쇄합니다.
- 2022 개정 교육과정 과목 이름을 적으면 교과(군)과 유형이 저절로 골라집니다.
- 관리자 프로그램에서 교직원에게 ‘교육과정 담당’ 권한을 주면 수강신청이 보입니다. 쓰지 않는 학교는 ‘기능 설정’에서 끕니다.
- 토요일·일요일에 수업 교체 표를 열면 다음 주 시간표가 나옵니다.

학교 서버와 교직원 PC가 모두 0.1.8이어야 수강신청이 보입니다. 다른 기능은 어느 쪽부터 업데이트해도 그대로 됩니다.

수강신청을 처음 쓰는 학교는 ‘수강신청 → 구글 연결’에서 코드를 한 번 붙여넣어 배포해야 합니다. 이후 버전에서 이 코드가 바뀌면 릴리즈 안내에 따로 적습니다.
