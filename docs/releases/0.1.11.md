# 교무톡 0.1.11

- 서버 자동 업데이트: 기본 폴더에 설치한 서버 PC에서 관리자 프로그램이 새 버전을 스스로 설치합니다. 켤 때와 평일 저녁 6시~아침 7시·주말에 서버를 멈추고 백업한 뒤 설치하고 다시 켜며, Windows 관리자 확인 창은 뜨지 않습니다. 서버 설치파일이 등록하는 예약 작업 ‘GyomuTalk Server Update’가 교무톡 서명이 맞는 설치파일만 설치합니다. ‘프로그램 업데이트’에서 끌 수 있습니다. 0.1.10에서 이번 버전으로 올릴 때만 확인 창에서 ‘예’를 한 번 누릅니다.
- 채팅: 엔터로 보낸 뒤 바로 이어서 입력할 수 있습니다.
- 붙여넣기: 복사한 사진이나 파일을 Ctrl+V로 채팅과 메시지에 넣습니다. 끌어다 놓아도 됩니다.
- 받는 사람 입력: 메시지의 ‘받는 사람’ 옆에 이름을 치면 맞는 선생님이 나오고 골라서 넣습니다.
- 조직도 작게 보기: ‘화면 · 조직도 보기’에서 ‘작게’를 고르면 한 사람이 한 줄로 보입니다.
- 연쇄 교체: 수업 둘이 잠시 겹치게 옮긴 뒤 하나 더 옮겨 겹침을 풀 수 있습니다. 겹침이 남으면 신청할 수 없습니다.
- 수업 불가 시간: 수업할 수 없는 시간을 표시하면 다른 선생님의 교체가 그 시간에 내 수업을 넣지 못합니다. 시간표 담당자는 모든 선생님의 시간을 표시하고, 다른 선생님은 내 줄만 누를 수 있습니다.
- 교체 도우미: 비울 날짜와 교시를 고르면 같은 날 교체를 먼저, 안 되면 그 주의 다른 날 교체를 찾아 줍니다. 원하는 점을 적으면 연결한 AI가 순서를 고릅니다(선생님 이름은 기호로 바꿔 보냅니다). 이미 시작했거나 지난 수업은 옮기지 않습니다.
- 동명이인: 시간표를 올릴 때 이름이 같은 계정이 여럿이면 과목마다 계정을 고르고, 고른 내용은 다음에 올릴 때 미리 채워집니다.

학교 서버와 교직원 PC를 어느 쪽부터 업데이트해도 됩니다. 수업 불가 시간·교체 도우미·동명이인 연결은 서버가 0.1.11이어야 쓸 수 있습니다.

수강신청에 쓰는 구글 코드는 0.1.8과 같아 다시 붙여넣지 않아도 됩니다.
