# 교무톡 0.0.6

- 작성창에 폴더를 끌어놓으면 하위 파일과 빈 폴더를 담은 ZIP 한 개로 첨부합니다.
- 관리자가 학교 설정 → 첨부 용량에서 2~10GiB를 선택할 수 있습니다. 기본값은 2GiB이며 파일 한 개와 메시지 전체에 적용합니다.
- 다운로드 진행률, 속도, 남은 시간을 볼 수 있습니다. 중단 후 같은 첨부를 다시 받으면 저장된 부분부터 이어받습니다.
- 재전송할 때 서버에 남은 완료 첨부를 재사용합니다.

학교 서버를 먼저 업데이트한 뒤 교직원용 메신저를 업데이트하세요. Windows에서 이어받을 때는 같은 이름과 저장 위치를 선택하세요.
