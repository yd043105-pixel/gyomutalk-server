# 교무톡 0.1.10

- 계정 삭제: 관리자 프로그램 ‘교직원·권한’에서 사용 중지한 계정에 ‘계정 삭제’ 버튼이 생겼습니다. 이름·부서·직책·로그인 이름·비밀번호를 지우고 권한·좌석 IP·조직도 폴더에서도 뺍니다. 이미 주고받은 메시지와 등록한 일정은 남고 ‘삭제된 사용자’로 보입니다. 되돌릴 수 없습니다.
- 조직도 순서: ‘조직도 폴더 관리’에서 ▲▼로 폴더 순서와 폴더 안 교직원 순서를 정합니다. 교직원 조직도에 그 순서대로 보이고 정렬 버튼이 ‘지정순’이 됩니다. 순서를 정하지 않은 학교는 지금처럼 가나다순입니다.
- 한글 입력: 한글을 치다가 다른 칸이나 버튼으로 옮겨도 조합 중인 마지막 글자가 빠지지 않게 했습니다.
- 업데이트 확인: 프로그램을 켜면 로그인 창에서 바로 새 버전을 확인합니다.

학교 서버와 교직원 PC를 어느 쪽부터 업데이트해도 됩니다. 계정 삭제와 조직도 순서는 서버가 0.1.10이어야 쓸 수 있고, 0.1.9 이하 교직원 PC는 조직도를 계속 가나다순으로 보여 줍니다.

수강신청에 쓰는 구글 코드는 0.1.8과 같아 다시 붙여넣지 않아도 됩니다.
