# 교무톡 0.1.6

- 학사일정은 이제 모든 교직원이 등록하고 자기 일정을 바꿉니다. 학사일정 담당은 다른 교직원의 일정도 바꾸거나 취소합니다.
- 모든 선생님이 학교 일정을 등록하고, 내가 등록한 일정은 눌러서 바꾸거나 취소합니다.
- 일정에 교시를 고르면 모든 선생님의 시간표 그 교시에 행사 이름이 보입니다.
- 시간표 담당 선생님은 확인하지 않은 수업 교체 신청이 있으면 ‘교체 신청 현황’을 열 때까지 5분마다 알림을 받습니다.
- 특별실 예약을 바꾸는 화면에 ‘예약 취소’ 버튼을 넣었습니다.

새 학사일정 기능은 학교 서버가 0.1.6이어야 동작합니다. 학교 서버를 먼저 업데이트하세요. 버전이 달라도 메시지는 그대로 주고받습니다.
