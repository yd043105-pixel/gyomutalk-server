# 교무톡 0.0.4

교직원 PC 전용 구성으로 정리한 공개 베타입니다.

## 변경사항
- 메시지 작성·메시지함 등 업무 창이 조직도보다 항상 앞에 고정되던 문제를 수정했습니다.
- 로그아웃·종료 시 업무 창을 닫고 암호화 임시저장을 보존합니다.
- 모바일 앱 연동, 가정통신문, 상담 예약, 수강신청, 학생·학부모 가입·학급·분반 관리와 소식 서버를 제거했습니다.
- 교직원 메시지·첨부·예약전송·읽음·회수·할 일·제출 수합·채팅·설문·시간표·학사일정·특별실과 구성원 관리를 유지합니다.
- 설치 구성과 설명서·다운로드 페이지를 PC 전용으로 정리했습니다.

## 업데이트 전 확인
서버관리자용은 서버 PC에, Windows 사용자용은 교직원 PC에 설치합니다. 진행 중인 작업을 저장하고 종료한 뒤 업데이트하세요. 서버는 중지·백업을 확인한 뒤 설치합니다.
앱 전용 데이터는 백업과 무결성 검사 후 정리합니다. 정리 백업은 자동 삭제하지 않습니다. 교직원 메시지·첨부·계정과 기존 동의 기록은 유지합니다. 운영 학교는 기능 범위에 맞는 약관을 검토해 관리자 화면에서 적용하세요.

## 검증 범위
PC 통합 83개, 실제 Windows 창 12개·제출 화면 8개·관리자 53개, 설치 마법사(Windows 9개·서버 10개), 데이터 정리 안전장치 8개 등을 개발 환경에서 검증했습니다. 해당 태그의 GitHub Actions에서 새 설치파일을 다시 빌드·검증합니다.
실제 학교망 두 PC 사이의 접속·원격 화면/입력, 실제 메일 수신·백신·재부팅·정전·별도 장치 복원은 학교에서 추가 시험해야 합니다. Windows 설치파일의 Authenticode 게시자 서명과 자동 업데이트의 Ed25519 서명은 별개입니다.

## 다운로드
`gyomutalk-server-0.0.4-setup-win-x64.exe`가 설치 마법사입니다. 같은 릴리즈의 `.sha256`으로 파일을 대조할 수 있으며 `appcast.xml`은 프로그램의 서명된 자동 업데이트 피드입니다.
