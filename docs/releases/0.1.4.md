# 교무톡 0.1.4

- ‘운영 현황’을 다른 화면과 같은 한 페이지로 정리했습니다. 자동검색·자동 구동·보안 검토 기록은 아래 ‘운영 설정’에서 엽니다.
- 교내 서버 자동검색, 서버 PC 자동 구동, 보안 도입 검토 기록, 프로그램 업데이트 창을 같은 모양으로 맞췄습니다.
- 파일 제출 현황에서 제출한 선생님은 초록색, 아직 내지 않은 선생님은 빨간색 카드로 보입니다.
- 수업 교체 표에서 같은 묶음수업은 같은 색으로 보입니다. 묶음마다 서로 잘 구별되는 색이 자동으로 정해집니다.
- ‘게시 시간표 인쇄’는 보고 있는 시간표를 인쇄한다는 뜻이 드러나게 ‘보고 있는 시간표 인쇄’로 바꿨습니다.

이번 버전은 학교 서버와 교직원용 메신저 중 어느 쪽을 먼저 업데이트해도 됩니다.
