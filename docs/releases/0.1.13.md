# 교무톡 0.1.13

0.1.11 이후 달라진 점입니다(0.1.12 내용 포함). 0.1.11에서 바로 올려도 아래가 모두 들어갑니다.

## 이번 0.1.13
- 교체하지 않는 시간: 시간표 담당자가 ‘교체 신청 현황’ → ‘교체하지 않는 시간’에서 창의적 체험활동처럼 매주 같은 시간(요일·교시·학년)을 등록합니다. 그 시간의 수업은 교체 판에 회색 칸으로 보이고, 선생님들은 옮기거나 그 시간으로 다른 수업을 넣을 수 없습니다. 시간표 담당자는 바꿀 수 있습니다.
- 교체 도우미: 같은 날 → 이번 주 다른 날 → 다음 주(교체할 수 있는 범위까지) 순으로 교체안을 찾습니다. 다른 주와 바꾸는 안에는 ‘다른 주 포함’이 붙습니다.

## 0.1.12에서 들어간 것
- 다음 주 수업과 교체: 수업 교체 판에서 내 수업을 고른 채 ‘›’로 다음 주로 넘기면 고른 수업이 위쪽에 ‘옮길 수업 · …’으로 따라가고, 그 주에서 바꿀 수 있는 수업이 초록색으로 보입니다. ✕를 누르면 고른 수업을 놓습니다.
- 교체 범위: 시간표 담당자가 ‘교체 신청 현황’의 ‘교체할 수 있는 범위’에서 같은 주만, 다음 주까지(처음 값), 2~4주 뒤까지 중에서 고릅니다. 다른 주와 바꾼 신청에는 ‘다른 주와 교체’ 표시가 붙고, 범위를 벗어난 신청은 서버가 받지 않습니다.
- 받은 파일: 누르면 묻지 않고 문서 폴더의 GyomutalkFiles(C:\Users\<사용자>\Documents\GyomutalkFiles)에 저장되고, 같은 이름이 있으면 ‘이름 (2)’로 저장됩니다. 오른쪽 클릭하면 ‘지정된 폴더에 다운로드’(저장 위치 표시), ‘다른 이름으로 저장’, ‘받은 파일 폴더 열기’가 나옵니다. 메시지함·채팅·파일 제출·ZIP 일괄 받기에 모두 적용됩니다.
- 처음 설치: ‘Windows 로그인 시 자동 실행’과 ‘이 Windows 계정에서 자동 로그인’이 켜진 채로 시작합니다. 여러 사람이 함께 쓰는 PC라면 자동 로그인을 끄세요. 이미 쓰던 PC의 설정은 바뀌지 않습니다.
- 업데이트: Windows 교무톡을 켜면 바로 새 버전을 확인하고, 바뀐 내용을 몇 줄로 보여 준 뒤 10초 뒤 저절로 설치합니다(‘나중에’로 미룰 수 있습니다). 업데이트할 때 ‘Windows 로그인 시 자동 실행’ 설정이 더는 바뀌지 않습니다.
- 서버 자동 업데이트: 서버 PC가 새 버전을 저절로 설치한 뒤, 다시 켜진 관리자 프로그램이 바뀐 내용을 몇 줄로 알려 줍니다.

교체하지 않는 시간·다음 주 교체·교체 범위는 학교 서버가 0.1.13이어야 모두 쓸 수 있습니다. 학교 서버와 교직원 PC를 어느 쪽부터 업데이트해도 됩니다.

0.1.11이 깔린 PC는 지금처럼 안내 창에서 ‘업데이트 설치’를 누르고, 서버 PC는 바뀐 내용 안내 없이 설치됩니다. 0.1.12가 깔린 PC는 몇 줄 요약 뒤 10초 뒤 저절로 설치되고, 서버 PC는 설치 뒤 바뀐 내용을 알려 줍니다.

수강신청에 쓰는 구글 코드는 0.1.8과 같아 다시 붙여넣지 않아도 됩니다.
