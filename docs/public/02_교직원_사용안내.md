# 교직원 사용 안내
## 1. 설치하고 로그인하세요
### Windows PC
02_설치파일 / 02_교직원_Windows의 EXE를 실행하고 설치 마법사의 안내를 따릅니다. 바탕화면 바로가기·Windows 로그인 후 자동 실행을 필요에 맞게 선택한 뒤 교무톡을 엽니다.
1. 학교 검색에서 학교명·지역을 확인하여 선택합니다. 목록이 없거나 서버를 찾지 못하면 학교 관리자에게 문의합니다.
2. 학교가 안내한 이름 아이디로 로그인합니다. 동명이인은 별도 안내된 계정을 사용합니다.
3. 최초 계정은 임시 비밀번호 12345678과 관리자가 전달한 계정별 활성화 코드로 활성화합니다. 안내 전문과 필수 항목을 확인한 뒤 개인 비밀번호 12~128자로 변경합니다.
4. 본인만 쓰는 기기에서 자동 로그인을 선택합니다. 공용 PC에서는 사용 후 로그아웃하세요.
### Android 교사용 앱
04_Android의 교사용 APK를 학교가 허용한 방법으로 설치합니다. 학생학부모용 APK와 다릅니다. 이 파일은 시험 서명본입니다. 학교 운영 주소와 신뢰할 수 있는 인증서가 준비되어야 연결할 수 있습니다.
### Mac 교직원 앱
‘이 Mac에 관하여’에서 칩이 Apple이면 AppleSilicon ZIP, 프로세서가 Intel이면 Intel ZIP을 선택합니다. 압축을 풀고 앱을 응용 프로그램 폴더로 옮깁니다. 이번 앱은 시험본이며 일반 배포용 Apple 서명·공증이 완료되지 않았습니다. 실행이 보안 정책으로 차단되면 관리자에게 문의하고 운영체제 보안 기능을 끄지 마세요.
### 기기별 메뉴는 다를 수 있습니다
Windows가 전체 업무 기능의 기준입니다. Mac·교사용 휴대폰은 메시지 확인과 시간표·학교 업무를 중심으로 제공하며 Windows 관리자 기능·원격지원·편집 도구 전체가 동일하게 제공되는 것은 아닙니다. 화면에 없는 기능은 Windows에서 처리하세요.
## 2. 메시지를 보내고 확인하세요
### 보내기
1. 조직도에서 대상자를 선택하고 ‘메시지’를 누릅니다. 전송 창의 받는 사람에서 실제 대상만 확인하고, 이름 옆 X로 제외할 사람을 삭제합니다. ‘나에게 전송’도 사용할 수 있습니다.
2. 제목은 필요할 때만 적습니다. 비워두면 본문 앞부분을 목록에 표시합니다. 본문은 일부만 한 줄로 보이고 긴 내용은 ...으로 줄여 표시합니다.
3. Windows에서는 글씨체·크기·강조를 조절하고 파일을 끌어다 놓아 첨부할 수 있습니다. 전송 전에 대상·본문·파일을 확인합니다.
4. 바로 보내거나 예약 시간을 지정합니다. 작성 중인 내용은 임시저장하고 임시저장 목록에서 다시 엽니다. 예약·임시저장 편집은 제공되는 Windows 화면에서 사용합니다.
### 읽기와 답장
받은함에서 메시지를 선택하면 본문과 첨부를 확인할 수 있습니다. Windows 읽기 창의 답장 버튼은 우하단에 표시됩니다. 파일은 업로드 후 30일 보관 기준이 있으므로 필요한 자료는 학교의 보관 기준에 맞게 처리하세요. 메시지 본문에 첨부와 같은 30일 만료를 적용하는 것은 아닙니다.
### 보낸 메시지 회수
안 읽은 수신자가 한 명 이상이면 회수할 수 있습니다. 일부가 읽었더라도 나머지 미확인 수신자가 있으면 가능합니다. 모두 읽으면 회수할 수 없습니다. 이미 본 내용·촬영한 화면·내려받은 파일까지 삭제하는 기능은 아닙니다.
### 접속 상태
조직도 상태 표시는 PC·모바일 연결과 자리비움 상태에 따라 바뀝니다. 마우스를 대면 상태 설명을 확인할 수 있습니다. 표시만으로 상대방이 내용을 읽었다고 판단하지 말고 메시지의 읽음 상태를 확인하세요.
## 3. 할 일과 제출 요청을 관리하세요
### 메시지에서 할 일 등록
메시지를 열면 기한·제출·준비 등 표현에서 추출한 할 일 후보가 말풍선으로 표시될 수 있습니다. 후보를 확인하고 필요한 항목만 선택한 뒤 추가합니다. 자동 추출만으로 할 일이 확정 등록되지는 않습니다.
기한은 문맥에 따라 잘못 해석될 수 있으니 직접 확인·수정하세요. 할 일 목록에서는 기한별 D-Day를 확인하고 완료 처리합니다. 외부 AI API에 메시지 본문을 전송하여 추출하는 방식이 아닙니다.
### 파일을 받아야 할 때
Windows 메시지 전송 창에서 ‘파일 제출 요청’을 선택하고 제출 대상·기한·안내를 확인하여 보냅니다. ‘할 일·제출’에서 요청과 수신자별 제출 현황을 확인하고 허용된 파일을 모아 받습니다.
제출자는 별도의 답장 메시지 없이 제출 화면에서 파일을 올립니다. 마감·종료 상태가 허용하는 동안 제출 파일을 회수하고 다시 제출할 수 있습니다. 단순히 답장에 첨부한 파일은 제출 요청의 제출 파일과 구분됩니다.
미제출 알림은 기한 이틀 전부터 하루 한 번 처리하는 기준이며 서버가 정상 실행 중이어야 합니다. 실제 기한·제출 상태·서버 시간을 함께 확인하세요.
### 원격지원·채팅·설문
Windows의 해당 메뉴에서 사용합니다. 원격지원은 상대방이 요청을 수락한 뒤 연결하며, 종료 시 세션을 끝냅니다. 교내 네트워크나 보안 프로그램이 차단하면 학교 담당자에게 확인을 요청하고 방화벽을 임의로 해제하지 않습니다.
> Mac·휴대폰에서 Windows와 같은 할 일·제출·원격지원 화면 전체를 제공하는 것으로 안내하지 않습니다. 위 기능이 필요한 경우 Windows 메신저를 사용하세요.
## 4. 가정통신문·시간표·학교 업무
### 학생·학부모에게 안내 보내기
권한이 있는 교직원은 ‘가정통신문’에서 내용을 작성하고 전체·학년·학급·분반 등 허용된 대상을 선택합니다. 특정 대상을 선택한 안내는 그 범위의 구성원과 연결된 보호자, 지정된 담당 교사가 확인합니다. 게시 전 대상을 다시 확인하세요.
첨부는 JPG·PNG 이미지로 한 장당 200KB 이하, 공지당 최대 5장입니다. 이 기준은 학생·학부모용 모든 공지 첨부에 적용합니다. 앱에서는 공지 안에서 이미지를 봅니다. 화면 촬영이나 재전달까지 막아주는 보안 기능은 아니므로 필요한 정보만 올리세요.
### 시간표와 예약
수업 업무 담당자가 학기 기초시간표를 등록하고 변경된 날짜의 시간표를 추가합니다. 일자별 파일이 없는 날은 기초시간표를 사용합니다. 업로드 후 해당 날짜·학년·교사의 표시 결과를 확인하세요. 학생 개인 수강 자료가 없으면 개인 시간표가 완성되지 않을 수 있습니다.
‘일정·예약’에서 학사 일정과 학교 행사를 확인하고 특별실을 예약합니다. 특별실은 1~7교시 범위이며 상담은 교사가 개방한 시간만 신청받습니다. 학교 설정에 따라 8교시·야간1·야간2 시간도 상담에 사용할 수 있습니다.
### 선택과목 신청 업무
‘수강신청’은 지정된 업무 담당자에게 표시합니다. 학년 단위로 1·2학년의 신청 회차·과목·학점·선택 규칙을 설정하고 신청 현황과 미신청자를 확인합니다. 3학년은 신청 대상에서 제외하며 과목 정원을 두는 방식이 아닙니다.
과목 유형은 공통과목·일반선택·진로선택·융합선택입니다. 학생 계정의 실제 신청 결과와 학점·규칙 검증을 확인한 뒤 확정합니다. 학부모는 학생을 대신하여 신청 내용을 변경하지 않습니다.
### 오류·정보 변경
학교 문의처에 기기·발생 시각·메뉴·오류 문구를 알려주세요. 앱의 오류·의견 기능을 이용할 때도 비밀번호·학생 명부·자녀 번호 등은 넣지 마세요. 문의·메일 수신처와 자동 접수 여부는 운영 학교가 설정합니다.
