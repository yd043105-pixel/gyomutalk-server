# 교직원 사용 안내

## 처음 실행
Windows는 교직원용 EXE 설치 마법사를 이용합니다. Mac은 칩에 맞는 시험 앱 ZIP을 사용합니다. 서버관리자용 설치본은 교직원 PC에 필요하지 않습니다. 학교를 선택하고 교내 자동검색으로 연결합니다. 처음에는 관리자 화면의 연결 확인 코드를 대조합니다. 학교 서버가 꺼져 있으면 로그인과 새 자료 수신을 할 수 없습니다.

본인 아이디와 초기 비밀번호 12345678, 개별 활성화 번호로 시작한 뒤 개인 비밀번호로 바꿉니다. 자동 로그인은 본인 PC에서만 켭니다. 번호·비밀번호를 공개 채팅에 올리지 마세요.

## 조직도와 메시지
조직도에서 사람을 골라 메시지를 보냅니다. 이름 우클릭에는 현재 사용할 수 있는 기능만 표시됩니다. PC 온라인·자리비움·오프라인 상태를 표시하고 상태에 마우스를 올리면 설명이 나옵니다. 휴대폰 상태는 표시하지 않습니다.

받는 사람은 선택된 사람만 표시되며 X로 뺄 수 있습니다. 제목은 선택 사항이며 비우면 본문으로 목록을 표시합니다. 파일을 끌어다 첨부하고 나에게 전송·예약전송·임시저장 목록을 사용합니다. 받은 메시지 목록은 한 줄로 표시하고 긴 내용은 생략합니다. 답장은 본문 스크롤 밖 우하단에서 누릅니다.

메시지 작성·메시지함 등 업무 창은 조직도와 독립적으로 앞뒤로 전환할 수 있습니다. 로그인 종료·프로그램 종료 시에는 함께 닫힙니다. 안 읽은 수신자가 한 명 이상 남았으면 보낸 메시지를 회수할 수 있으며 이미 읽은 사람의 사본까지 삭제되는 것으로 해석하지 마세요.

## 저장과 첨부
메시지 본문은 PC에 암호화 저장하며 서버에서 전달이 끝난 본문을 정리합니다. 저장하지 못한 PC가 있어도 서버의 본문은 최대 30일 뒤 정리됩니다. 다른 PC에서 예전 본문이 보이지 않을 수 있습니다. 첨부는 업로드 후 30일 동안 내려받습니다. 채팅 대화와 파일은 메시지 본문과 보관 방식이 다르므로 필요한 자료를 학교 기준에 맞게 보관하세요.

## 할 일과 제출
메시지의 할 일 후보 말풍선에서 내용·기한을 확인한 뒤 선택해 추가합니다. 자동으로 등록되지 않습니다. 나의 할 일에서 기한별 D-Day와 완료 상태를 확인합니다.

파일 제출 요청은 `할 일·제출 → 파일 제출·수합`에서 확인합니다. 답장 없이 파일을 제출할 수 있고 요청이 진행 중인 동안 회수·재제출합니다. 보낸 사람은 이름별 제출 상태, 면제, 미제출자 안내와 ZIP 일괄 받기를 사용합니다. 창이 좁아지면 한 줄의 이름 수가 줄고 긴 파일명은 생략됩니다. 마우스를 올리면 전체 이름을 확인합니다.

## 학교 업무
채팅·설문, 개인 시간표, 학사일정·특별실 예약을 사용합니다. 시간표 담당자가 기초·일자별 변경 시간표를 올립니다. 변경이 없는 날은 기초시간표를 따릅니다. 특별실 예약은 1~7교시입니다. 원격지원은 Windows에서 상대방의 명시적 수락 후 사용하며 연결 가능한 학교망인지 확인합니다.

휴대폰 앱, 가정통신문, 학생·학부모 가입·명부, 상담 예약·수강신청은 제공하지 않습니다. Mac은 Windows와 일부 서식·원격지원 등 기능에 차이가 있으므로 해당 메뉴의 실제 제공 범위에 따릅니다.

## 오류와 업데이트
오류 신고·개선 의견에서 발생 시각·메뉴·오류 문구를 적습니다. 비밀번호와 학교 명부를 첨부하지 마세요. 자동 오류 접수·메일은 학교 관리자가 설정하고 수신 시험한 뒤 작동합니다. 업데이트 알림에서 변경사항을 확인하고 진행 중인 작성을 마친 뒤 설치합니다.
