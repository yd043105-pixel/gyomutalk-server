- 교사·학생·학부모 휴대폰 연동, 가정통신문, 상담 예약, 수강신청, 학생·학부모 가입·자녀 연결·학급 및 분반 관리, 휴대폰 접속 표시와 소식 서버/외부 중계 기능을 제거했습니다. 화면 메뉴·권한 설정·API·설치 구성·다운로드 안내에서도 제거했습니다.

## 데이터 정리
정리 전에 소스·기존 전달본·설치본·운영 DB·관리자 설정을 백업하고 해시와 무결성을 검증했습니다.
현재 개발 PC의 기존 운영 데이터에서 앱 전용 테이블 ExternalFiles, ExternalOutbox, GuardianRequests, BridgeNonces, ElectiveManagers를 제거했습니다. 다섯 테이블은 모두 0건이었습니다. 유지 대상 48개 테이블의 내용을 백업 DB와 전수 대조해 동일함을 확인했고 SQLite 무결성·외래키 검사를 통과했습니다.
다른 학교의 데이터는 새 서버의 1회 정리 과정에서 먼저 백업합니다. 유지 테이블이 제거 대상 테이블을 외래키로 참조하면 정리를 중단합니다. 앱 소유 외부 파일만 검증·백업 후 삭제하며 교직원의 첨부 폴더는 삭제 대상이 아닙니다.
Android/iOS 설치본과 학생·학부모 설명서를 현재 전달 폴더에서 제거했습니다. 분리 전 작업 폴더는 비활성 이력으로 안내하고 모바일 자동 빌드를 제거했습니다. 실제 빌드 소스는 분리된 세 PC 저장소입니다.

## 확인하지 못한 사항과 백업 보관
학교망에서 두 실제 PC 사이의 접속과 원격 화면·입력, 실제 SMTP 수신, 학교 백신·보안 프로그램, 실제 재부팅·정전·별도 장치 백업 복원은 이 개발 환경에서 확인하지 않았습니다. 다운로드 페이지의 브라우저 검증 도구는 초기화 오류로 실행되지 않았습니다. HTML 참조·파일·릴리즈 동작과 공개 배포 HTTP 응답을 검증했습니다.
따라서 ‘모든 유지 기능과 실제 운영 환경이 정상’이라는 백업 삭제 조건은 아직 확정하지 않았습니다. 정리 백업은 삭제하지 않았으며 자동 삭제도 설정하지 않았습니다. 검증 완료 뒤 정리 전용 백업만 삭제해야 합니다. 운영 메시지나 일반 서버 백업을 함께 삭제하지 마세요.
기본 데이터 폴더의 정리 백업 이름은 retired-app-backups입니다. 백업 DB를 운영 중인 서버 위에 덮어쓰지 마세요. 복구가 필요하면 서버를 중지하고 정리 전 코드·설치본과 DB를 함께 격리된 시험 환경에서 확인합니다.

## 설치본과 공개 배포
Windows/server의 로컬 시험 버전은 기존 0.0.3을 유지합니다. Mac은 기존 미출시 시험 버전 1.0.0입니다. 이번에 새 프로그램 공개 릴리즈를 게시하거나 기존 릴리즈 설치파일을 덮어쓰지 않았습니다.
설치본은 전달 폴더의 02_설치파일에서 역할별로 선택합니다. 다운로드 웹페이지는 PC 전용 설명과 실제 GitHub 공개 릴리즈를 연결하도록 수정했습니다.
