# PC 프로그램 업데이트

휴대폰 앱을 제외한 Windows 교무톡, Windows 관리자 프로그램, Mac 교무톡에 적용됩니다. 정식 공개 릴리즈가 생기면 하루에 한 번 새 버전을 확인하고 설치를 안내합니다. 자동 확인은 설정에서 끄거나 다시 켤 수 있습니다.

Windows 교무톡은 왼쪽 아래 설정 → 프로그램 업데이트, 관리자 프로그램은 왼쪽 아래 프로그램 업데이트, Mac 교무톡은 내 계정 → 프로그램 업데이트를 사용하세요. 설치파일의 게시자 서명을 검증한 뒤 업데이트합니다. 작성 중인 메시지와 다른 업무 창을 저장하고 닫은 뒤 진행하세요.

서버관리자 프로그램은 서버를 정상 중지하고 데이터베이스와 첨부파일을 백업한 뒤 설치합니다. 운영 설정의 전체 첨부 백업과 백업 장치가 준비되어야 합니다. 백업 또는 정상 중지가 실패하면 설치하지 않습니다. 업데이트 후 이전에 실행 중이던 서버를 다시 가동하므로 관리자는 두 서버의 정상 가동과 로그인·메시지 전송을 확인하세요. 서버 업데이트 중에는 사용자 접속이 잠시 중단됩니다.

학교 네트워크에서 GitHub에 연결할 수 있어야 자동 확인·다운로드가 가능합니다. 연결이 차단되면 학교 관리자가 공식 릴리즈 설치파일로 수동 업데이트하세요. 현재 공개 릴리즈는 준비 중이며, Mac과 휴대폰 앱은 출시 준비 단계입니다. 업데이트 파일의 무결성 서명은 Windows 배포용 전자서명 또는 Apple의 배포 서명·공증을 대신하지 않습니다.
