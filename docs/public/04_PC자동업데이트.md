# PC 프로그램 업데이트

휴대폰 앱을 제외한 Windows 교무톡, Windows 관리자 프로그램, Mac 교무톡에 적용됩니다. 프로그램을 시작할 때마다, 그리고 켜 둔 채로는 하루에 한 번 새 버전을 확인하고 설치를 안내합니다. 서버와 교직원 프로그램의 버전이 달라도 로그인과 메시지는 그대로 되므로, 어느 쪽을 먼저 업데이트해도 됩니다. 자동 확인은 설정에서 끄거나 다시 켤 수 있습니다.

Windows 교무톡은 왼쪽 아래 설정 → 프로그램 업데이트, 관리자 프로그램은 왼쪽 아래 프로그램 업데이트, Mac 교무톡은 내 계정 → 프로그램 업데이트를 사용하세요. 서명된 자동 업데이트 피드와 설치파일의 무결성을 검증한 뒤 업데이트합니다. 작성 중인 메시지와 다른 업무 창을 저장하고 닫은 뒤 진행하세요.

서버관리자 프로그램은 서버를 정상 중지하고 데이터베이스와 첨부파일을 백업한 뒤 설치합니다. 운영 설정의 전체 첨부 백업과 백업 장치가 준비되어야 합니다. 백업 또는 정상 중지가 실패하면 설치하지 않습니다. 업데이트 후 이전에 실행 중이던 서버를 다시 가동하므로 관리자는 교내 업무 서버의 정상 가동과 로그인·메시지 전송을 확인하세요. 서버 업데이트 중에는 사용자 접속이 잠시 중단됩니다.

학교 네트워크에서 GitHub에 연결할 수 있어야 자동 확인·다운로드가 가능합니다. 연결이 차단되면 학교 관리자가 공식 릴리즈 설치파일로 수동 업데이트하세요. 서버관리자용·Windows용 0.1.3 공개 릴리즈를 제공합니다. Mac 0.1.3는 시험용 사전 릴리즈로 구분하며 Apple 정식 서명·공증과 정식 자동 업데이트는 준비 단계입니다. 휴대폰 앱은 운영하지 않습니다. 업데이트 파일의 무결성 서명은 Windows 배포용 전자서명 또는 Apple의 배포 서명·공증을 대신하지 않습니다.
