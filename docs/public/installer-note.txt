교무톡 관리자 및 서버 - 시작 안내

1. 시작 메뉴 → 교무톡 관리자 및 서버 → 관리자 프로그램을 엽니다.
2. 처음에는 ‘이 PC 시험 · 외부 접속 없음’을 선택합니다.
3. 최초 관리자 비밀번호 12~128자를 지정한 뒤 ‘서버 시작’을 누릅니다.
4. 상태가 ‘실행 중’이면 ‘관리자 로그인’에서 admin으로 로그인합니다.
5. 가상 교직원 계정을 만들어 메시지를 시험합니다. 실제 학생 자료는 넣지 않습니다.

서버 폴더의 EXE를 직접 더블클릭할 필요가 없습니다.
관리자 프로그램 자동 실행과 서버 자동 시작은 각각 선택하는 별도 설정입니다.
Windows 사용자 로그인 전 상시 실행은 별도 운영 구성이 필요합니다.

함께 제공된 설명서
00_먼저읽기: 기기별 설치 파일과 시험 순서
01_관리자_설치와운영: 설치, 계정, 접속, 백업, 업데이트, 장애 대응
02_교직원_사용안내: PC·교사용 앱 사용
03_학생학부모_앱안내: 가입, 자녀 연결, 학교 소식

설명서 원문은 설치 폴더의 docs에도 있습니다.
다른 PC·휴대폰 접속은 학교가 승인한 HTTPS 주소와 인증서·운영 설정을 준비한 뒤 시험하세요.
localhost는 현재 기기만 뜻합니다. 방화벽·백신·인증서 검증을 끄지 마세요.

설정 예시는 초안입니다. 학교의 약관·개인정보·보안 검토가 완료된 운영 설정을 대신하지 않습니다.
실제 운영 자료와 비밀 설정은 프로그램 폴더 밖에 보관하며, 설치 파일과 함께 공유하지 않습니다.
기존 서버 업데이트는 복구 가능한 백업을 확인하고 자동 시작·감시·서버를 정상 중지한 뒤 진행합니다.
