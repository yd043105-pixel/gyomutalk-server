# 관리자 설치·운영 안내

## 1. 서버 PC에 설치
Windows 10(2004 이상) 또는 Windows 11 x64 PC에 서버관리자용 EXE를 실행합니다. 설치 마법사에서 바탕화면 바로가기와 Windows 로그인 시 자동 실행 여부를 선택합니다. 설치 후 **교무톡 관리자**를 엽니다. PowerShell이나 server 폴더의 EXE를 직접 실행하지 않습니다.

관리자 프로그램에서 서버 시작·중지, 자동 시작, 학교 설정, 구성원·권한, 시간표, 특별실·학사일정, 약관, 운영 기록과 오류 신고를 관리합니다. 자동 시작과 서버 자동 구동은 관리자 화면에서 각각 확인하세요. Windows에 운영 계정으로 로그인해야 시작되는 구성인지 실제 재부팅으로 확인합니다.

## 2. 학교와 보안 설정
학교명·학교 식별 정보·문의처를 입력합니다. 학교의 적용 기준에 맞게 도입 승인과 운영 검토 자료를 내부에 보관합니다. 운영 책임자와 문의처는 학교별로 확정하며 개발자의 개인정보를 학교 문의처로 복사하지 않습니다.

관리자 비밀번호는 교직원의 초기 비밀번호와 다르게 설정합니다. 최초 시험은 로컬 체험으로 진행하고, 운영 연결은 학교의 허용 네트워크와 HTTPS 인증서를 준비한 뒤 설정합니다. 방화벽·백신을 일괄 해제하지 않고 필요한 프로그램·포트만 학교 담당자와 확인합니다. 교무톡은 학교망 안에서만 씁니다. 학교 밖 접속 기능이 없으므로 외부 서버나 Cloudflare Tunnel 같은 터널을 준비하지 않습니다.

## 3. 약관·교직원 등록
학교 검토용 약관 초안은 확정되지 않은 상태로 제공됩니다. 운영 주체·문의처·보유 기간·처리 근거를 검토하고 확정한 파일을 관리자 화면에서 적용합니다. 기존 동의 기록은 삭제하거나 덮어쓰지 않습니다.

구성원 화면에서 이름·부서·직책·좌석 IP(선택)와 권한을 설정합니다. 교직원은 본인 이름으로 로그인하며, 동명이인은 로그인 이름 뒤에 .2처럼 숫자를 붙여 구분합니다. 새 교직원의 초기 비밀번호는 12345678이고, 처음 로그인하면 약관을 확인하고 바로 개인 비밀번호로 바꿉니다. 30일 안에 로그인하지 않은 계정은 초기 비밀번호가 막히므로 ‘계정 초기화’를 눌러 다시 열어 줍니다. 교직원이 직접 ‘계정 신청’을 하면 관리자가 승인합니다. 한 계정은 한 번에 한 컴퓨터에서만 로그인됩니다.

학사일정 담당·특별실 운영 담당·시간표 담당을 지정하고 특별실 목록을 입력합니다. 관리자 프로그램의 ‘기능 설정’에서 시간표·채팅·할 일·설문·학사일정·특별실 예약·원격 지원 가운데 학교에서 쓰는 기능만 켭니다. 끈 기능은 교직원 메신저 메뉴에서 바로 사라지고, 다시 켜면 기존 자료가 그대로 보입니다. 시간표 담당자는 시간표 화면의 ‘기초시간표 · 묶음수업’에서 나이스 기초시간표 파일을 학년 칸마다 올립니다. 한 학년만 다시 올려도 다른 학년은 그대로 남습니다. 여러 반이 같은 시간에 나뉘어 듣는 수업은 학년 → 과목 → 분반 순으로 골라 묶음으로 지정합니다. 교체 신청은 ‘교체 신청 현황’에서 승인하면 시간표에 반영됩니다. 특별실 예약은 1~7교시를 사용합니다. 학생·학부모 계정·상담·수강신청·분반 명부 관리 메뉴는 없습니다.

## 4. 교직원 PC 연결
교직원용 설치본을 다른 PC에 설치합니다. 로그인 화면에서 ‘교내 자동검색’을 누르면 같은 학교망의 서버를 찾습니다. 자동검색이 막힌 교내 네트워크에서는 관리자 화면에 표시된 주소를 안내합니다. 첫 연결에서 확인 코드가 같은지 대조합니다. 다르면 접속을 중단하고 학교 담당자에게 확인하세요.

## 5. 매일 점검
서버 상태와 저장 공간·CPU·RAM을 확인합니다. 자동 백업은 별도 저장장치와 암호화를 준비한 뒤 켭니다. 같은 디스크의 복사본은 디스크 장애에 대비한 백업을 대신하지 않습니다. 장애 메일은 SMTP와 수신처 설정 후 실제 수신까지 시험합니다. UPS·정전 복구와 백신·학교 보안 프로그램의 허용 여부는 실제 서버에서 확인합니다.

## 6. 업데이트·복원
새 버전이 나오면 업데이트 안내 창에서 바뀌는 내용을 확인합니다. 관리자 업데이트 전에는 진행 중인 작업을 마치고 서버를 중지하고 데이터 백업을 확인합니다. 공개 릴리즈와 SHA-256을 대조한 공식 설치본을 사용하세요.

앱 기능을 제거하며 생긴 정리 백업은 데이터 폴더의 `retired-app-backups`에 보관됩니다. 자동으로 지우지 않습니다. 남은 기능과 복원 시험까지 확인한 뒤 관리자 검토로 정리합니다. 설치 폴더의 파일을 임의로 지워 DB를 정리하지 마세요.

## 7. 도입 전 시험
가상 계정 두 명으로 로그인·승인·비밀번호 변경, 메시지·첨부·회수·예약전송, 파일 제출·회수·재제출, 채팅·설문·할 일, 시간표·일정·특별실 중복 예약을 확인합니다. 다른 PC 접속, 서버 재시작 후 자동 구동, 복원, 오류 신고 메일도 학교 환경에서 시험합니다. 개발 환경 통과가 학교 방화벽·백신·메일·정전을 검증한 뜻은 아닙니다.
