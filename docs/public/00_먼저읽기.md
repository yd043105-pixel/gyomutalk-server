# 교무톡 PC 사용 시작

교무톡은 학교가 직접 운영하는 교직원용 PC 메신저입니다. 휴대폰 앱은 운영하지 않으며, 학생·학부모 가입과 가정통신문·상담 예약·수강신청 기능은 제공하지 않습니다.

## 설치 순서
1. 서버 PC: `02_설치파일/01_서버관리자_Windows`의 EXE를 설치합니다.
2. 바탕화면의 **교무톡 관리자**를 열고 학교 이름과 관리자 계정을 정한 뒤 **서버 시작**을 누릅니다. server 폴더의 실행파일을 직접 열 필요가 없습니다.
3. 교직원 Windows PC: `02_설치파일/02_교직원_Windows`의 EXE를 설치합니다.
4. 교직원 Mac: `02_설치파일/03_교직원_Mac`에서 Apple Silicon 또는 Intel에 맞는 ZIP을 선택합니다. Mac 시험본은 Apple 정식 서명·공증이 완료되지 않았습니다.
5. 교직원 PC에서 교내 자동검색을 누르거나 서버 주소를 넣어 연결하고, 서버 관리자 화면의 연결 확인 코드를 대조합니다.
6. 가상 교직원 두 명으로 메시지·첨부·제출·채팅·설문·시간표·예약을 시험합니다.

## 남는 기능
조직도·즐겨찾기·PC 접속 및 자리비움, 메시지·첨부·예약전송·임시저장·읽음·회수, 할 일 추천·D-Day, 파일 제출·수합, 채팅·설문, 개인 시간표, 학사일정·특별실 예약, 구성원·권한 관리, 오류 신고와 업데이트를 유지합니다. 기능별 플랫폼 차이는 교직원 설명서를 확인하세요. 원격지원은 Windows끼리 사용합니다.

## 폴더 안내
- `01_설명서`: 관리자·교직원 안내 PDF와 원문

- `03_관리자_준비양식`: 학교에서 확정할 운영 검토 초안
- `99_검증결과`: 검증 범위·파일 목록·SHA-256
