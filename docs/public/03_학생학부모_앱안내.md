# 학교톡 학생·학부모 안내
## 1. 학교를 선택하고 가입하세요
### 설치할 앱
Android는 02_설치파일 / 04_Android의 학교톡 학생학부모용 APK를 학교가 허용한 방법으로 설치합니다. 교사용 교무톡과는 별도입니다. 현재 시험 서명본이며 정식 스토어 배포본이 아닙니다. iPhone·iPad용 설치 파일은 이번 전달본에 없습니다. 학교의 추후 설치·배포 안내를 기다려 주세요.
### 학생은 학교에서 받은 계정으로
학교 검색에서 소속 학교와 지역을 확인합니다. 학교가 배부한 계정·초대 정보로 최초 활성화를 진행하고 약관 전문과 필요한 항목을 확인합니다. 별도 학생 가입은 학교에서 허용한 경우에만 진행합니다. 다른 학생 계정을 빌려 쓰지 마세요.
### 학부모는 본인의 계정으로
1. 학부모로 가입하고 본인의 임시계정으로 로그인합니다. 학생 아이디로 로그인하는 절차가 아닙니다.
2. 설정의 자녀 연결에서 학교가 전달한 자녀의 8자리 고유번호를 대소문자까지 정확히 입력합니다.
3. 학교의 연결 확인이 끝나면 자녀에게 해당하는 자료를 봅니다. 학교가 별도로 승인한 즉시 연결 방식에서는 번호 확인 후 연결됩니다.
4. 재학 자녀가 둘 이상이면 설정에서 자녀를 추가하고 해당 자녀의 고유번호를 입력합니다. 자녀별 연결 상태를 확인하세요.
> 자녀 고유번호는 개인 연결 정보입니다. 단체 대화방·공개 화면에 올리지 마세요. 잘못된 자녀가 연결되거나 번호가 유출되면 학교에 연결 해제·번호 재발급을 요청하세요.
### 동의와 계정 관리
약관·개인정보 안내를 각각 열어 읽고 필요한 동의·확인 항목에 직접 체크합니다. 서명 이미지를 올리는 절차가 아닙니다. 공용 기기에서는 로그아웃하고 가입·정정·탈퇴 문의는 운영 학교의 안내된 문의처로 요청하세요.
## 2. 학교 소식을 확인하세요
### 공지·가정통신문
공지 목록에서 내용을 열고 본문과 이미지를 확인합니다. 학교가 선택한 학년·학급·분반 등의 대상에 해당하는 안내만 표시합니다. 학부모는 연결이 확인된 자녀의 범위에 해당하는 자료를 봅니다.
이미지 첨부는 한 장당 200KB 이하, 공지당 최대 5장으로 공지 안에서 봅니다. 첨부는 서버 보관 기간이 있으므로 예전 이미지가 만료될 수 있습니다. 읽을 수 없는 자료는 학교에 문의하세요. 자료를 다른 사람에게 무단 재전달하지 마세요.
### 시간표·급식·일정
학교가 등록한 기초시간표와 날짜별 변경 시간표를 확인합니다. 변경 파일이 없는 날은 기초시간표를 표시합니다. 개인 수강 정보가 등록되기 전에는 학급 기준으로 표시되거나 일부 개인 시간이 없을 수 있습니다.
급식과 학사 일정은 학교가 연결·등록한 자료를 기준으로 확인합니다. 내용이 없거나 실제 일정과 다르면 학교에 알려주세요. 날짜·선택한 자녀·학급을 먼저 확인하면 혼동을 줄일 수 있습니다.
### 상담 신청
교사가 열어둔 날짜와 시간 중 가능한 시간을 선택하여 신청합니다. 예약 결과와 취소·변경 가능 여부를 확인하세요. 다른 사람의 상담 내용이나 신원은 공개하지 않습니다. 급한 상담은 앱 예약만 기다리지 말고 학교 문의처로 연락하세요.
### 학생 선택과목 신청
학교가 개방한 신청 기간에 학생 본인 계정으로 신청합니다. 1·2학년의 해당 학년 과목·학점·선택 규칙을 확인하고 제출한 결과를 다시 확인하세요. 과목 정원에 따른 선착순 접수 방식이 아니며 3학년은 신청 대상이 아닙니다. 학부모 계정에서는 학생의 신청을 대신 변경하지 않습니다.
> 앱 종료 상태의 휴대폰 푸시 알림은 현재 제공·검증 범위에 포함되지 않습니다. 시험 중에는 앱을 열어 새 내용을 확인하세요. 중요한 안내는 학교가 정한 대체 수단으로도 확인합니다.

### 개인정보는 어디에 문의하나요?
학교가 앱의 약관·개인정보 안내에 등록한 문의처로 열람·정정·삭제·처리정지 등을 요청합니다. 오류 신고에 비밀번호나 자녀 번호를 적지 마세요. 화면을 첨부한다면 다른 학생의 이름 등은 가립니다.
학생 정보는 재학 기간을 기준으로 관리합니다. 학교가 졸업 대상과 처리 시각을 등록하면 해당 시각부터 로그인 차단과 자동 탈퇴·파기 절차가 적용됩니다. 학부모는 다른 재학 자녀가 있으면 계정을 유지하며 마지막 자녀 졸업 시 함께 처리합니다.
기기에 따로 저장하거나 전달받은 사본까지 서버가 모두 지우지는 못합니다. 필요가 끝난 자료는 학교의 안내에 따라 정리하세요.
