교무톡 관리자 및 서버 설치

교내 업무 서버 PC 또는 학생·학부모용 학교 소식 서버 PC를 선택하세요.
각 서버 역할에는 관리자 프로그램이 함께 설치됩니다.
관리자 프로그램 안에서 서버 가동, 교직원·권한, 학급·분반, 특별실,
학생·학부모, 학교 약관·개인정보, 오류·의견을 관리합니다.

설치는 서버 프로그램과 운영 도구를 배치합니다.
HTTPS 인증서·전용 Windows 운영 계정·백업·UPS·메일·Cloudflare 설정은
완료 후 열리는 ‘서버 설치 안내’의 순서로 진행하세요.
설치 마법사는 서버를 즉시 시작하거나 학교 방화벽·예약 작업을 변경하지 않습니다.

이 PC에서 먼저 시험하려면 설치 후 시작 메뉴의
‘교무톡 관리자 및 서버 → 관리자 프로그램’을 실행하세요.
화면에서 최초 관리자 비밀번호 12~128자를 입력하고 서버 시작·중지를 선택합니다.
서버 폴더의 EXE를 직접 더블클릭하는 방식은 최초 설정을 대신하지 않습니다.
시험 데이터는 화면에 표시된 별도 폴더에 저장하며 실제 운영 자료를 넣지 않습니다.
바탕화면 바로가기와 Windows 로그인 후 프로그램 자동 실행은 설치 중 선택할 수 있습니다.
서버를 시작한 뒤 왼쪽 관리 메뉴에서 해당 서버의 관리자 계정으로 로그인하세요.
교내용·학교 소식 서버의 로그인은 분리되며 비밀번호는 파일에 저장하지 않습니다.

데이터·첨부·비밀 설정은 프로그램 폴더 밖에 보관하세요.
프로그램 제거는 서버 계정 탈퇴나 개인정보 파기를 뜻하지 않습니다.
운영 중인 서버 업데이트는 백업 후 시작·감시를 중지하고 진행하세요.

두 서버를 한 Windows 환경에 설치하는 것만으로 보안 격리가 되지는 않습니다.
역할 분리·운영 준비 조건은 기존 서버 운영 안내를 따릅니다.

학교별 도입·운영 내부결재 승인 문서는 해당 학교에 보관하세요.
학교 검색 등록 승인은 필요한 학교장 결재·학운위 심의·보안 검토를 대신하지 않습니다.
실제 승인 문서는 공개 설치본이나 개발자 신청 메일에 첨부하지 않습니다.
