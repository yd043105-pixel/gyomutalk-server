교무톡 관리자 및 학교 업무 서버 설치

학교의 교직원 PC 메신저를 운영하는 관리자용 설치본입니다.
관리자 프로그램에서 서버 시작·중지·자동 구동과 구성원·권한, 시간표,
학사일정·특별실, 약관·개인정보, 오류 신고와 자원 현황을 관리합니다.
휴대폰 앱과 학생·학부모용 서버·가정통신문·상담·수강신청은 제공하지 않습니다.

설치 마법사에서 바탕화면 바로가기와 Windows 로그인 후 자동 실행을 선택합니다.
설치 후 ‘교무톡 관리자’를 열어 학교·관리자 계정과 운영 설정을 준비하고 서버를 시작합니다.
server 폴더의 EXE를 직접 실행할 필요가 없습니다.
최초 시험에는 가상 자료만 사용하고, 교직원 PC에서 연결 확인 코드를 대조합니다.
관리자 비밀번호·활성화 번호는 개별 관리하고 공개 저장소에 넣지 않습니다.

데이터·첨부·운영 비밀과 백업은 프로그램 설치 폴더 밖에 보관하세요.
서버를 업데이트하기 전에 진행 중인 작업을 마치고 서버 중지·백업을 확인합니다.
프로그램 제거는 계정 탈퇴나 개인정보 파기를 대신하지 않습니다.
실제 학교의 방화벽·백신·메일·백업·UPS·재부팅 자동 구동은 학교 환경에서 시험하세요.
학교별 도입·운영 승인 및 검토 기록은 해당 학교에 보관합니다.
