# 교무톡 서버관리자

학교가 직접 운영하는 교직원 PC 메신저입니다. 휴대폰 앱과 학생·학부모 가입, 가정통신문, 상담 예약, 수강신청, 소식 서버 연동은 제거했습니다.

## 시작하기
- [설치와 사용 순서](docs/public/00_먼저읽기.md)
- [관리자 안내](docs/public/01_관리자_설치와운영.md)
- [교직원 안내](docs/public/02_교직원_사용안내.md)

서버는 관리자 프로그램에서 가동합니다. 메시지·파일 제출·할 일·채팅·설문·시간표·학사일정·특별실 예약과 학교별 계정·권한 관리를 유지합니다. 원격지원은 Windows에서 사용합니다. Mac은 별도 GitHub macOS 실행기에서 빌드·시험하며 정식 Apple 서명·공증 전 시험본을 정식 배포본으로 안내하지 않습니다.

## 개발과 배포
.NET SDK는 global.json의 고정 버전을 사용하며 패키지는 --locked-mode로 복원합니다. Windows의 네이티브 UI 테스트는 Windows에서, Mac의 실제 앱 테스트는 macOS에서 실행합니다. 앱 데이터와 운영 비밀은 저장소·설치본에 넣지 않습니다.

현재 버전은 0.1.2입니다. Windows/server는 서명된 자동 업데이트 피드와 설치파일을 함께 게시합니다. Mac은 Apple 정식 서명·공증 전 시험용 사전 릴리즈로 구분합니다. 이전 릴리즈 자산은 덮어쓰지 않습니다. 자동 업데이트는 각 제품의 서명된 공개 릴리즈 피드를 사용합니다.

기존 데이터는 앱 전용 항목을 백업·검증한 뒤 정리합니다. 유지 기능의 검증이 모두 끝나기 전에는 retired-app-backups를 삭제하지 않습니다. 세부 검증 범위는 설치 안내와 정리 결과를 확인하세요.
